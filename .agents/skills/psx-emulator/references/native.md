# Native execution and build

Linux only. Build and verify locally; no hosted CI.

Host component `pcsx-redux` builds the committed registered
`third_party/pcsx-redux-agentic` submodule. Run `bin/harness setup --component
pcsx-redux`, then `bin/harness runtime status` and `bin/harness runtime missions`.
Dependency installation requires the requesting project's explicit authorization.

Managed setup requires the root stage-0 gitlink, fork HEAD and every recursive
submodule revision to agree. Tracked regular files/symlinks must match committed
blobs and modes; unexpected untracked or ignored build inputs refuse. Only fixed
Release products and explicitly named LuaJIT generated source paths are permitted.
Present generated bytes require their exact previous successful fork build
receipt; setup never blesses altered generated inputs or silently resets work.

The release Make build retains the approved SDL3 prefix and linkage check. Its v2
receipt binds committed source forests, recursive pins, generated bytes, executable,
SDL, embedded resources and native state schema. Lua physical files and compiled raw
chunks have different hashes. Verify both through the bounded catalogue query.
An included Lua edit must trigger an actual incremental rebuild before accepting
its resulting catalogue; include directives alone do not prove that behavior.

Checked state v6 capture/restore uses [Runtime's settled-boundary contract](runtime.md#checked-boundary).
Validate malformed/topology/media/card predicates before mutation. Preserve
CPU/CD/SPU/MDEC fields and deferred owning-string `loadSafe` lifecycle.
Postcommit host-file CREATE/open failure returns `CommitFailed`, pauses and emits
no Loaded event; no rollback or host filesystem transaction.

Prefer existing bulk bindings in [API](api.md), [History](history.md),
[Audio](audio.md), [CD-ROM](cdrom.md) and [Memory cards](memcard.md).
Keep mission composition and remaining semantic correlation in Lua.
Native implementations must preserve ownership and admission:

- Checked CPU/CD/card observations retain full save serialization, readback
  validation, device predicates and lease cleanup. Copy fields/bytes before lease
  release; allocate Lua values afterward. No narrowed admission shortcut.
- History/worker ranges copy under one mutex. Snapshots own payloads and joined
  Audio; exports and CD analysis reuse them with complete-capture refusals.
- Audio copies batches before Lua allocation; PCM streams directly to raw/WAV.
- ISO listing walks each ancestor once. Cards share SIO's chain parser, validate
  edits before commit and check flush write/close failures.
- MMIO/VRAM packers produce probes; guest stores use the existing executor.
  State selection validates all wire bytes, decodes the selected envelope through
  native `pb`, and shares schema descriptors/native byte scanning for comparison.

Verify changed behavior with existing local build/checks and a focused runtime run.
Measure complete caller operations before claiming performance gains.
Preserve frozen failed and successful evidence. Do not grow temporary controllers,
proof/grant frameworks, or recursive inventory campaigns. Source inspection alone
does not establish DSP/media safety or hardware fidelity.
