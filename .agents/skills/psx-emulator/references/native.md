# Native execution and build

Linux is the only maintained host platform. Build and verify locally; hosted CI is retired.

The active host component is `pcsx-redux`, sourced from the committed registered
`third_party/pcsx-redux-agentic` submodule. Run `bin/harness setup --component
pcsx-redux`, then `bin/harness runtime status` and `bin/harness runtime missions`.
Dependency installation requires the requesting project's explicit authorization.

Managed setup requires the root stage-0 gitlink, fork HEAD and every recursive
submodule revision to agree. Tracked regular files/symlinks must match committed
blobs and modes; unexpected untracked or ignored build inputs refuse. Only fixed
Release products and the nine named LuaJIT generated source paths are permitted.
Present generated bytes require their exact previous successful fork build
receipt; setup never blesses altered generated inputs or silently resets work.

The release Make build retains the approved SDL3 prefix and linkage check. Its v2
receipt binds committed source forests, recursive pins, generated bytes, executable,
SDL, 54 resources and native state schema. Lua physical files and compiled raw
chunks have different hashes. Verify both through the bounded catalogue query.
An included Lua edit must trigger an actual incremental rebuild before accepting
its resulting catalogue; include directives alone do not prove that behavior.

State v6 adds checked prepared restore/capture and native memory-card readback.
Running/in-Execute, active recorder/events, pending loads and Busy leases refuse.
Malformed/topology/media/card predicates validate before mutation. Preserve the
fork's CPU/CD/SPU/MDEC fields and deferred owning-string `loadSafe` lifecycle.
Postcommit host-file CREATE/open failure returns CommitFailed, pauses and emits no
Loaded event; no rollback or host filesystem transaction is promised.

Scanner, VRAM, and checked CPU observation APIs perform bulk work from one Lua
call. `PCSX.captureCPUChecked()` preserves complete checked save serialization,
native readback validation, cards/device predicates, and lease cleanup. It copies
CPU fields and safe memory words before releasing the lease, then allocates Lua
values. It avoids decoding the whole state in Lua; it is not a CPU-only admission
shortcut. Persisted-state validation remains schema-aware and bounded.

Bulk Lua work remains in `src/lua/missions`: `snapshot.lua` and `state.lua` parse
persisted states, `support.lua` encodes JSON, `frames.lua` converts BGR555
screenshots, `packets.lua` parses GPU words, `vram.lua` assembles uploads, and
history/audio modules export individual records. Measure these complete caller
paths before selecting another native API; acquisition alone does not qualify
whole-mission performance. Keep semantic correlation and mission composition in
Lua where native batching does not justify moving them.

Verify changed behavior with the existing local build/checks and a focused runtime
run. Measure the complete caller operation before claiming performance gains.
Preserve frozen failed and successful evidence. Do not grow temporary controllers,
proof/grant frameworks, or recursive inventory campaigns. Source inspection alone
does not establish DSP/media safety or hardware fidelity.
