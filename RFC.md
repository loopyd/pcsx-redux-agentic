# Changes to public behavior

For PCSX-Redux Agentic API, CLI, save-state, or protocol changes, explain the
concrete before/after behavior and affected callers. State supported versions,
compatibility limits, runtime bounds, and any migration procedure. Include
measurements when claiming performance gains.

Review the actual shipped change and its focused local validation. The fork does
not maintain the upstream hosted RFC moratorium, stakeholder notification workflow,
or other cloud automation. Follow the requesting project's authorization and
acceptance rules; a user-authorized implementation does not need a new waiting
period invented from upstream policy.

PSX guest libraries in `src/mips` retain their own upstream provenance. Preserve
licenses and history when host-specific maintenance changes the fork.
